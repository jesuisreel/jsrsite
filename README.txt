ЗАПУСК
  Двойной клик по index.html  или  start.bat (http://localhost:8000, нужен Python).

КАК ВСТАВИТЬ КАРТИНКИ
  1. На сайте везде, где должна быть картинка, нарисована пунктирная рамка с названием.
  2. Положите файл в папку images/<папка листа>/ с именем = название из рамки.
     Формат: png, jpg, webp или gif (любой).  Перезагрузите страницу (F5) — рамка заменится картинкой.
  3. Полный список всех ожидаемых файлов — slots.txt (или кнопка «Список картинок» вверху сайта).
  Из имени файла убираются символы  \ / : * ? " < > |   (например  Submarine-mounted Mark 20S Bidder Torpedo.png)

  Папки:  cover, patch, fleet, classes, slang, dict, equip, os, proto, shop, goodship, ghost, cats, cross,
          faces (лица на «Барражах»), barrages (гифки на «Барражах»), misc.
  Широкие картинки без названия: имя вида r33.png = «строка 33 листа» (см. slots.txt).
  Кроме того, в любую ячейку данных можно вписать images/misc/файл.png или прямую ссылку на картинку.

Обложка: images/cover/event.png (ивент), oc.png, meta.png.
Флотостроение: images/fleet/<Корабль>.png и широкие r<строка>.png (см. slots.txt).
